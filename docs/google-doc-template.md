# Cold DM Google Doc template

Paste this into the Google Doc whose ID is `CONFIG.DOC_ID`. Keep the `Template:` / `Subject:` / `Body:` markers exactly as written. You can have as many first-email templates as you want. `followup_1` and `followup_2` are reserved for the auto sequence.

---

Template: default

Subject: {{first_name}}, quick question about {{company}}
Subject: Idea for {{company}}
Subject: {{first_name}} — 30 seconds on {{role}}

Body:

Hi {{first_name}},

I noticed {{company}} and thought it was worth a short note.

{{first_name}}, I would love to learn more about the {{role}} work you are doing.

Best,
Pranav

Template: xyz_experience

Subject: {{first_name}}, my time at XYZ × {{company}}
Subject: What I learned at XYZ that maps to {{company}}

Body:

Hi {{first_name}},

I recently spent time at XYZ working on similar problems to what {{company}} is tackling in {{role}}.

Would you be open to a brief chat?

Best,
Pranav

Template: followup_1

Subject: Re: checking in
Subject: {{first_name}}, bumping this once

Body:

Hi {{first_name}},

Just bumping this in case it got buried. Happy to send a tighter version if useful.

Best,
Pranav

Template: followup_2

Subject: Re: last note from me
Subject: Closing the loop, {{first_name}}

Body:

Hi {{first_name}},

Last note from me — I will close the loop here. If timing is better later, I am easy to reach.

Best,
Pranav
